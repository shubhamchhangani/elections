# तस्वीरें — अब Gemini की ज़रूरत नहीं

सब कुछ कोड से बनता है। कोई फ़ाइल डाउनलोड करने या AI से बनवाने की ज़रूरत नहीं रही।

## चुनाव चिन्ह (12)

`src/symbols.js` में सीधे SVG के रूप में बने हैं — कमल, हाथ, सेब, अलमारी,
सिलाई की मशीन, गुब्बारा, कोट, चारपाई, आईस क्रीम, अंगूर, तकिया, स्कूल का बस्ता।

पेज में ये **inline** जाते हैं, इसलिए:
- कोई अलग फ़ाइल डाउनलोड नहीं होती — पेज उतना ही तेज़ खुलता है
- हर स्क्रीन पर एकदम साफ़ (SVG है, धुंधला नहीं होता)
- रंग या मोटाई बदलनी हो तो `src/symbols.js` में एक जगह बदलो

## WhatsApp की preview तस्वीरें (27)

```bash
npm run og
```

`scripts/og.js` चलता है — SVG बनाकर macOS के `qlmanage` (WebKit) से PNG रेंडर करता है
और `sips` से 800×418 पर काटता है। नतीजा `public/og/` में। हर फ़ाइल ~40KB
(WhatsApp की 300KB की सीमा से बहुत नीचे)।

**हर वार्ड की तस्वीर में उसी वार्ड के असली चुनाव चिन्ह दिखते हैं** — यानी वार्ड 24 की
preview में आईस क्रीम, अंगूर और तकिया नज़र आते हैं। यही उसे बाक़ी हर forward से अलग बनाता है।

> यह सिर्फ़ **macOS** पर चलता है (`qlmanage` और `sips` Apple के हैं)।
> Cloudflare पर build के वक़्त यह नहीं चलता — तस्वीरें repo में पहले से मौजूद रहती हैं।

## कुछ बदलना हो तो

| क्या | कहाँ |
|---|---|
| चिन्ह की आकृति | `src/symbols.js` |
| OG तस्वीर का डिज़ाइन, रंग, शब्द | `scripts/og.js` |
| बदलने के बाद | `npm run og && npm run build` फिर push |

⚠️ **WhatsApp preview को हफ़्तों cache रखता है और मिटाने का कोई तरीक़ा नहीं।**
तस्वीर बदलने के बाद पुराना लिंक पुरानी तस्वीर ही दिखाता रहेगा —
नया दिखाना हो तो लिंक के आगे `?v=2` लगाकर भेजें।
